## 🚀 Loyiha haqida

**Everything for Claude Code (ECC)** — Claude Code va sun'iy intellekt agentlari bilan ishlovchi dasturchilar uchun maxsus yaratilgan ochiq manba platformasidir. Barcha manbalar Sammi Academy uslubidagi ixcham 4 ustunli qulay kartalarda, to'liq o'zbek tilida va nozik did bilan ishlangan Obsidian Black & Bronze Brown interfeysida taqdim etiladi.

---

## ✨ Asosiy imkoniyatlar

- **Qora va bronza-jigarrang premium dizayn**: `#090807` chuqur obsidian fon, `#F7F4EF` issiq oq matn va `#A47550` bronza aksentlari.
- **Haqiqiy Custom Select Dropdown**: Brauzerning standart menyusisiz, to'liq React asosida yozilgan, toifalar va tavsiflar bilan boyitilgan suzuvchi tanlov komponenti.
- **2x4 Ixcham Kartalar Tizimi**: Ekranda roppa-rosa 4 ta ustunli (2 qatorda 4 tadan) qilib joylashtirilgan 8 ta sara loyiha.
- **Batafsil Modal Oyna**: Kartani bosganda loyihaning to'liq tavsifi, texnologik steki, o'rnatish buyruqlari va Antigravity bilan mosligi chiqadi.
- **Bir bosishda `git clone`**: Barcha ochiq manbalarni bir zumda klonlash imkoniyati.
- **To'liq o'zbek tilida**: Mahalliylashtirilgan tushunarli qo'llanmalar va tavsiflar.

## 📦 Tavsiya etilgan 8 ta ochiq manbali vosita

1. **EveryThingForClaudeCode** (`AbdullayevTemurmalik/EveryThingForClaudeCode`) — Rasmiy ochiq kutubxona va AI dasturchilar platformasi.
2. **ECC (Affan Mustafa)** (`affaan-m/ECC`) — Coding agentlar uchun original muhandislik sikli, ko'nikmalar (skills) va AgentShield tizimi.
3. **OmniRoute** (`cheaper-inference/OmniRoute`) — AI Gateway, arzon va tezkor inference boshqaruvi.
4. **UI/UX Pro Max Skill** (`nextlevelbuilder/ui-ux-pro-max-skill`) — AI coding agentlar uchun dizayn tizimlari va UI/UX ko'nikmalari.
5. **Headroom** (`headroomlabs-ai/headroom`) — LLM tokenlarini tejovchi kontekst optimallashtirish shlyuzi.
6. **FreeLLMAPI** (`tashfeenahmed/freellmapi`) — Bepul sun'iy intellekt modellarini bitta OpenAI-mos API'ga birlashtirish.
7. **Claude-Mem** (`thedotmack/claude-mem`) — Agentlar uchun doimiy xotira (persistent memory) tizimi.
8. **Strix** (`usestrix/strix`) — Ochiq manbali avtomatlashtirilgan kiberxavfsizlik va zaifliklarni aniqlash agenti.

## 🛠️ Lokal o'rnatish va ishga tushirish

```bash
# Repozitoriyani klonlash
git clone https://github.com/AbdullayevTemurmalik/EveryThingForClaudeCode.git

# Papkaga kirish
cd EveryThingForClaudeCode

# Bog'liqliklarni o'rnatish
npm install

# Ishlab chiqarish rejimida build qilish
npm run build

# Serverni ishga tushirish
npm run start
```

Brauzerda `http://localhost:3000` manzilini oching.
