# Xavfsizlik Siyosati (Security Policy)

## Qo'llab-quvvatlanadigan Versiyalar

Xavfsizlik yamoqlari faqat joriy ishlab chiqarish versiyasi uchun chiqariladi:

| Versiya | Qo'llab-quvvatlanadi |
| ------- | -------------------- |
| 1.0.x   | ✅ Ha                |
| < 1.0   | ❌ Yo'q              |

---

## Zaifliklar Haqida Xabar Berish

Agar ushbu loyihada yoki unda ko'rsatilgan manbalar bilan bog'liq xavfsizlik muammosini aniqlasangiz:

1. Ommaviy GitHub Issues bo'limida xavfsizlik zaifliklarini **ochmang**.
2. Muammo haqida to'g'ridan-to'g'ri repository egasiga [GitHub Security Advisory](https://github.com/AbdullayevTemurmalik/EveryThingForClaudeCode/security/advisories) orqali xabar bering.
3. Hisobotda quyidagi ma'lumotlarni ko'rsating:
   - Zaiflik tavsifi va xavf darajasi
   - Qayta takrorlash (reproduction) qadamlari
   - Tavsiya etilgan tuzatish yo'li (mavjud bo'lsa)

Xabaringiz 48 soat ichida ko'rib chiqiladi. Hamkorligingiz va platforma xavfsizligiga qo'shgan hissangiz uchun rahmat!
